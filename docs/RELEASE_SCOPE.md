# First Release Scope

The first release should be usable by a real single-location gym without requiring advanced features.

## Must-have owner/admin features
- Login
- Dashboard
- Add/edit/search members
- Membership plans
- Record fee payments
- Partial payments
- Due/overdue tracking
- Payment history
- Receipts
- Expenses
- Attendance
- Basic reports

## Must-have member features
- Login
- Own membership status
- Plan, join date, expiry date, next due date
- Outstanding balance
- Own payment history
- Receipts
- Own attendance history
- Gym announcements

## Nice-to-have in first release if stable
- Workout plans
- Progress tracking
- Trainer/staff management

## Not required for first release
- Online gateway payments
- WhatsApp API automation
- QR attendance
- Multi-branch support
- GST invoicing
- Class booking
- Native Play Store release

## First-release definition of done
- Persistent production database
- Role-based access verified
- Financial totals tested
- Mobile and desktop responsive UI
- Public PWA URL opens directly
- Android installation from browser works where supported
- Backup/export path exists
- No development launcher in the production user flow
